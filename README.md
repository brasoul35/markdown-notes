# Markdown Notes

A simple note-taking app that runs entirely in the browser. You can write your
notes in Markdown and see a live preview next to the editor. Notes are saved in
the browser's local storage, so they stay even after you close the page.

## Features
1. **Create, edit, and delete notes** - manage a list of notes from the sidebar.
2. **Live Markdown preview** - the note is converted from Markdown to HTML as you
   type (supports headings, bold, italic, inline code, links, and bullet lists).
3. **Local storage saving** - notes are saved in the browser so they are kept
   between visits.
4. **Search** - filter your notes by typing in the search box.
5. **Dark mode** - switch between a light and dark theme, and the choice is
   remembered for next time.
6. **Export as .md** - download the current note as a Markdown file.
7. **Word and character count** - a live count below the editor updates as you
   type.

## How to run
No installation or build step is needed. Just open `index.html` in a web browser.

## Reference project
This project was inspired by the open-source Markdown note app **Notable**:
https://github.com/notable/notable

My version is a much smaller, from-scratch implementation and does not use any
of Notable's code. It only keeps the same basic idea (writing notes in Markdown
with a live preview).
